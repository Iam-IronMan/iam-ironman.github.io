# Jiahang Liu

Personal homepage featuring research in 3D generation and computer graphics.

This is a static website with no build dependencies.

## Local preview

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

## Content

- `index.html`: profile, data and systems work, education and thesis.
- `content.js`: selected research and publication links.
- `style.css`: responsive design.
- `assets/`: project and thesis figures.

## GitHub Pages

Publish from the `main` branch and the repository root. `.nojekyll` serves these files as a static site.

## Video demos

Selected project demos play silently and loop while visible. Scrolling them out of view pauses playback; native controls allow manual playback and fullscreen. Reduced-motion and data-saving preferences disable automatic playback. Video provenance is listed in `assets/videos/sources.json`.
